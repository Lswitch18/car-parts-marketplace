**Data:** Maio de 2026
**Projeto:** DAIG (Digital A.I. Garage)
**Mercado:** Japão

---

## 1. O Projeto

DAIG é um **marketplace B2B2C de peças automotivas japonesas** com **sistema de logística próprio** (WMS/TMS/OMS), operando 100% no Japão.

- **Identidade visual e logo** — Já criados e finalizados
- **Domínio pretendido:** daig.jp

### Como Funciona na Prática

**Para o vendedor (desmanche):**

1. Acessa o site, cadastra a peça com fotos e informações

2. Define o preço e publica — o anúncio vai ao ar

3. Quando vende, o sistema gera a etiqueta de envio e agenda a coleta

4. A transportadora parceira retira a peça e entrega ao comprador

5. O vendedor recebe o pagamento direto na conta

**Para o comprador (oficina, entusiasta, empresa):**

1. Busca a peça no site por marca, modelo ou categoria

2. Encontra a peça, vê fotos, preço e avaliação do vendedor

3. Compra com cartão de crédito — pagamento processado na hora

4. Acompanha a entrega pelo rastreamento em tempo real

5. Recebe a peça em casa ou na oficina

**Para a transportadora parceira:**

1. Recebe a solicitação de coleta pelo sistema

2. Retira a peça no desmanche

3. Entrega ao comprador

4. Tudo rastreado e registrado no software DAIG

### Quem Usa a Plataforma

- **Desmanches** (解体屋) que têm peças para vender
- **Oficinas mecânicas** que precisam de peças
- **Entusiastas JDM** que restauram carros
- **Empresas** (logística, frotistas, montadoras)

### Diferenciais

| Funcionalidade | DAIG | Concorrentes |
|---------------|------|-------------|
| Marketplace | Sim | Yahoo Auctions, Mercari |
| Logística própria (coleta + entrega) | Sim | Não |

| Identificação de peças por IA (foto) | Sim | Não |

## 2. Estágio Atual — Sistema Completo e Funcionando

### Plataforma Marketplace
- Site completo com catálogo, busca, filtros por marca/modelo
- Cadastro e login (email + Google)
- Anúncios com fotos, preço, condição
- Chat comprador/vendedor
- Checkout com pagamento por cartão (Stripe)
- Dashboard do vendedor (vendas, anúncios, faturamento)
- Dashboard administrativo (gráficos, gestão de usuários, transações)
- IA que identifica peças automaticamente por foto

### Sistema de Logística (Logistix) — Apenas Software
- **WMS** — Controle de estoque por zona/armazém
- **TMS** — Gestão de transportes e rotas
- **OMS** — Gestão de pedidos
- **App mobile para motoristas** (coleta/entrega com scanner e GPS)
- **Rastreamento público** — página /rastreio sem login
- **Mapa GPS** — motoristas em tempo real
- **Geração de etiquetas** — código de barras e QR code

> **Atenção:** Não temos operação logística própria. Temos apenas o sistema de software. Precisamos de uma parceria com transportadora (Yamato, Sagawa, SENIO) para usar a operação física deles.

### API B2B — Nosso Sistema de Logística como Serviço

Empresas de logística podem contratar nosso sistema (API privada) para usar na operação delas.

- **Contrato mínimo de 2 anos**
- Elas usam nosso software de gestão logística (WMS/TMS/OMS) dentro da própria empresa
- Integração via API privada com o sistema delas

### Gestão de Dados e Informação
A plataforma gera dados de alto valor sobre o mercado de peças automotivas no Japão:

- **Preços praticados** — Saber quanto cada peça está sendo vendida no mercado
- **Demanda por peça/modelo** — Quais peças têm mais procura, quais modelos
- **Perfil dos compradores** — Quem compra, de onde compra, com que frequência
- **Tendências de mercado** — Quais peças estão valorizando, quais estão saindo

**Valor comercial:** Esses dados podem ser vendidos ou usados como argumento para parcerias com montadoras, seguradoras e empresas de logística.

# GAID — Configuração GitHub Actions
Este projeto usa GitHub Actions para automatizar o deploy da plataforma GAID.

## Variáveis Necessárias (Secrets)
- `SUPABASE_ACCESS_TOKEN`: Token de acesso pessoal do Supabase.
- `VITE_SUPABASE_URL`: URL do seu projeto.
- `VITE_SUPABASE_ANON_KEY`: Chave anon do seu projeto.
- `VITE_APP_URL`: https://gaid.jp
